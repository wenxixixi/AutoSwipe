# ⬡ AutoSwipe - 自动滑动

一个 Android 悬浮窗工具，用于自动模拟向上滑动手势，实现短视频自动刷视频功能。

## ✨ 功能特点

- 🎯 **自动向上滑动** - 模拟手指滑动，自动刷新视频
- ⚙️ **可调参数** - 滑动次数、滑动间隔自由设置
- 🪟 **悬浮窗控制** - 可拖动的悬浮面板，随时开始/停止
- 📊 **实时进度** - 显示当前滑动进度
- 🔒 **安全可靠** - 使用 Android 无障碍服务，无需 Root

## 📱 使用场景

- 抖音自动刷视频
- 快手自动翻页
- 其他需要向上滑动的应用

## 🚀 快速开始

### 方法一：下载预编译 APK（推荐）

1. 点击本页面右侧的 **Actions** 标签
2. 选择最新的成功构建
3. 在 **Artifacts** 区域下载 `AutoSwipe-APK`
4. 安装到手机即可使用

### 方法二：自行编译

```bash
# 克隆仓库
git clone https://github.com/YOUR_USERNAME/AutoSwipe.git
cd AutoSwipe

# 编译 Debug 版本
./gradlew assembleDebug

# APK 输出路径
app/build/outputs/apk/debug/app-debug.apk
```

## 📖 使用步骤

1. **安装 APK** → 打开应用
2. **开启无障碍服务** → 点击「去开启」→ 找到「自动滑动」→ 打开
3. **开启悬浮窗权限** → 点击「去开启」→ 允许显示悬浮窗
4. **启动服务** → 点击「🚀 启动服务」→ 返回桌面
5. **打开短视频 APP** → 如抖音、快手等
6. **设置参数** → 滑动次数（默认100）、间隔（默认2秒）
7. **点击「开始」** → 自动开始向上滑动！

## 📋 系统要求

- Android 7.0 (API 24) 或更高版本
- 需要开启无障碍服务权限
- 需要悬浮窗权限

## 🛠️ 技术架构

| 组件 | 说明 |
|------|------|
| `SwipeAccessibilityService` | 无障碍服务，执行滑动手势 |
| `FloatingWindowService` | 悬浮窗控制面板 |
| `MainActivity` | 主界面，权限引导 |

## ⚠️ 注意事项

- 本工具仅供学习交流使用
- 请合理使用，遵守各平台规则
- 滑动间隔建议设置 1.5~3 秒，太快可能导致视频加载跟不上
